MimiqCircuitsBase.DecompositionBasis — Type
DecompositionBasis

Abstract type for decomposition targets that define a set of terminal operations and how to decompose non-terminal operations.

A DecompositionBasis combines two concerns:

  1. What is terminal: Operations that should not be decomposed further.
  2. How to decompose: The transformation logic for non-terminal operations.

Interface

Subtypes must implement:

  • isterminal(basis, op): Return true if op is in the target set.
  • decompose!(builder, basis, op, qtargets, ctargets, ztargets): Append decomposed instructions to builder for non-terminal operations.

Examples

struct CliffordT <: DecompositionBasis end

# Define terminal operations
isterminal(::CliffordT, ::GateH) = true
isterminal(::CliffordT, ::GateS) = true
isterminal(::CliffordT, ::GateT) = true
isterminal(::CliffordT, ::GateCX) = true
isterminal(::CliffordT, ::Operation) = false

# Define decomposition (can delegate to rewrite rules)
function decompose!(builder, ::CliffordT, op::Operation, qt, ct, zt)
    return decompose_step!(builder, CanonicalRewrite(), op, qt, ct, zt)
end

See also CanonicalBasis, RewriteRule, decompose.

Circuit([instructions])

├── H @ q[1]
└── CX @ q[1], q[2]

julia> push!(c, GateRX(π / 4), 1)
2-qubit circuit with 3 instructions:
├── H @ q[1]
├── CX @ q[1], q[2]
└── RX(π/4) @ q[1]

├── H @ q[1]
├── CX @ q[1], q[2]

├── H @ q[1]

graph(circuit)

Return the dependency graph of the circuit, as a Graphs.SimpleDiGraph.

Vertex i is the i-th instruction. There is an edge from i to j when j is the next instruction after i acting on one of the same qubits, bits or z-variables. Observables that read the whole state, such as Amplitude or BondDim, depend on every qubit.

MimiqCircuitsBase.reorder_qubits — Method
reorder_qubits(c::Circuit, perm)

Return a new Circuit with every qubit index rewritten through perm.

perm[q] == new_position: a 1-qubit gate previously acting on qubit q ends up on qubit perm[q] in the result.

The permutation is also folded into any operation that embeds qubit references outside getqubits(inst). Today the only such payload is Amplitude.bs, a computational-basis state keyed by qubit index; after a permutation the rewritten Amplitude must read the same amplitude of the same quantum-state component. The general- operation wrappers (IfStatement, WhileStatement, Repeat) forward the permutation to their inner op so a wrapped Amplitude is rewritten too. Classical-bit conditions on IfStatement / WhileStatement are qubit-independent and stay unchanged. The gate- only wrappers (Control, Inverse, Power, Parallel) cannot hold an Amplitude at the type level (T<:AbstractGate), so no override is needed.

Classical-bit (getbits) and z-register (getztargets) indices are left alone — they index a side register that the qubit permutation does not touch. The output circuit is therefore equivalent to c from the point of view of the post-execution cstate / zstate; only the internal qubit ordering changes.

Throws ArgumentError when perm is not a permutation of 1:numqubits(c).

MimiqCircuitsBase.remove_swaps — Function
remove_swaps(circuit; recursive=false)

Remove all SWAP gates from a quantum circuit by tracking qubit permutations and remapping subsequent operations to their correct physical qubits.

Returns a tuple of:

  • new_circuit: Circuit with SWAP gates removed and operations remapped
  • qubit_permutation: Final permutation where qubit_permutation[i] gives the physical qubit location of logical qubit i

Arguments

  • circuit: Input quantum circuit
  • recursive=false: If true, recursively remove swaps from nested blocks/subcircuits

Details

When a SWAP gate is encountered on qubits (i, j), instead of keeping the gate:

  1. The qubit mapping is updated to track that logical qubits i and j have exchanged physical positions
  2. All subsequent gates are automatically remapped to operate on the correct physical qubits

This transformation preserves circuit semantics while eliminating SWAP overhead.

Examples

julia> c = Circuit()
       push!(c, GateH(), 1)
       push!(c, GateSWAP(), 1, 2)
       push!(c, GateCX(), 2, 3)
       new_c, perm = remove_swaps(c)
       new_c
3-qubit circuit with 2 instructions:
├── H @ q[1]
└── CX @ q[1], q[3]

julia> perm  # Logical qubit 1 is at physical position 2, logical 2 at position 1
3-element Vector{Int64}:
 2
 1
 3
julia> c = Circuit()
       push!(c, GateSWAP(), 1, 2)
       push!(c, GateSWAP(), 2, 3)
       push!(c, GateCX(), 1, 3)  # After swaps: logical 1 -> physical 3, logical 3 -> physical 1
       new_c, perm = remove_swaps(c)
       new_c

MimiqCircuitsBase.pauli_based_computation — Method
pauli_based_computation(c::Circuit; basis=CliffordTBasis(), magic_states=false)

Rewrite a circuit in Pauli-based computation form: a sequence of $\pi/8$ Pauli product rotations (RPauli with angle $\pm\pi/4$) and Pauli product measurements (MeasurePauli), with no Clifford gates left.

The circuit is first decomposed with basis, which must produce Clifford+T gates, the measurements and resets listed below, and the conditional operations described below. Those measurements, resets and conditional Pauli products are kept whole, whatever basis does with them. Each Clifford $C$ is then moved past every later T gate and measurement, conjugating them: a T gate on qubit $q$ becomes the rotation $\exp(-i \frac{\pi}{8} C^\dagger Z_q C)$, and a measurement of $Z_q$ becomes a measurement of $C^\dagger Z_q C$. When the conjugated observable has a minus sign, the rotation angle is negated, or the measured bit is flipped with Not.

The Cliffords left after the last measurement do not change any outcome and are dropped. The result therefore reproduces the measurement statistics of c, not its final quantum state, and each rotation is exact up to a global phase. Classical operations and annotations are kept in place; barriers and identity gates are dropped.

Measurements, resets and conditional operations

  • Measure, MeasureX, MeasureY, MeasureXX, MeasureYY, MeasureZZ and MeasurePauli measure a Pauli product $P$ and become a MeasurePauli of $C^\dagger P C$.
  • A reset in the Z, X or Y basis (Reset, ResetX, ResetY) measures $Z$, $X$ or $Y$ into a new bit, then applies, if the outcome is 1, the Pauli that maps the $-1$ eigenstate to the $+1$ one: $X$ for the Z and Y bases, $Z$ for the X basis. The measure-and-reset operations (MeasureReset, MeasureResetX, MeasureResetY) do the same with the bit they are given.
  • An IfStatement whose body is made only of Pauli operators applies one Pauli product $P$ when its condition holds. The body can be GateX, GateY, GateZ, GateID, a PauliString, or a Block, Parallel, Repeat or GateCall holding only such operations, at any depth. It becomes one IfStatement of the PauliString $C^\dagger P C$ with the same condition. The phase of $P$ is dropped, as it only multiplies one classical branch.
  • A conditional T or T† gate becomes a conditional RPauli rotation with the same condition.

Any other conditional operation is refused. After a conditional Clifford gate, the accumulated Clifford would depend on the condition bits, so the later rotations and measurements could not be computed before the circuit runs.

Magic-state injection

With magic_states=true the rotations are removed as well. Each $\pi/8$ rotation on $P$ consumes a magic state $T\ket{+}$, prepared with PrepareStateT on one ancilla qubit that is reused for every rotation:

  1. MeasurePauli of $P \otimes Z$ on the data qubits and the ancilla, with outcome $m_1$.
  2. MeasurePauli of $X$ on the ancilla if $m_1 = 0$, of $Y$ if $m_1 = 1$ (swapped for a negative angle), with outcome $m_2$. The choice is made by two IfStatements.

When $m_2 = 1$ the rotation is applied together with a Pauli byproduct $P$. Byproducts are not corrected with gates. Instead, their product $F$ is tracked in classical bits, the Pauli frame: one bit for the X part and one for the Z part of $F$ on each data qubit. When $m_2 = 1$, Xor operations multiply the frame by $P$. Each later $m_1$ or measurement outcome whose Pauli anticommutes with $F$ is flipped in place, again with Xor, so the bits hold the outcomes of the ideal circuit.

A conditional Pauli, including the correction of a reset, is not applied either: it multiplies the frame when its condition holds, with the same Xor operations. A condition other than a single bit equal to 1 is first evaluated into one extra bit with SetBit1 and 3-bit And operations; each condition bit compared with 0 is flipped with Not while it is read and flipped back right after. A conditional T or T† gate is refused, since a magic state cannot be injected conditionally.

Every classical operation added is therefore a 3-bit Xor or And, a Not or a SetBit1, whatever the size of the circuit. The result contains only Pauli product measurements, magic-state preparations and classical logic.

Bit layout

With $n_b$ the number of bits of the decomposed circuit and $r$ its number of resets, the $j$-th reset writes its outcome to bit $n_b + j$. With magic states, let $n'_b = n_b + r$, $n$ be the number of qubits and $t$ the number of T and T† gates of the decomposed circuit. The ancilla is qubit $n + 1$. The $k$-th rotation writes $m_1$ to bit $n'_b + 2k - 1$ and $m_2$ to bit $n'_b + 2k$. The frame bits of qubit $q$ follow: the X part at bit $n'_b + 2t + q$ and the Z part at bit $n'_b + 2t + n + q$. The condition of a conditional Pauli, when it needs its own bit, goes to bit $n'_b + 2t + 2n + 1$.

Errors

Throws a DecompositionError if basis cannot decompose an operation, such as a noise channel. Throws an ArgumentError if the decomposed circuit contains anything other than Clifford+T gates, the measurements and resets listed above, the conditional operations listed above, classical operations and annotations: for example a non-Clifford gate, a conditional Clifford gate or a conditional measurement. With magic_states=true, a conditional T or T† gate also throws an ArgumentError.

Examples

Prepare a Bell pair, apply a T gate to qubit 2 and measure both qubits:

julia> c = push!(Circuit(), GateH(), 1);

julia> push!(c, GateCX(), 1, 2);

julia> push!(c, GateT(), 2);

julia> push!(c, Measure(), 1:2, 1:2);

julia> pauli_based_computation(c)
2-qubit, 2-bit circuit with 3 instructions:
├── R("XZ", π / 4) @ q[1:2]
├── MP(X) @ q[1], c[1]
└── MP(XZ) @ q[1:2], c[2]

The Clifford before the T gate is $C = \mathrm{CX}_{12} H_1$, so the T gate becomes a $\pi/8$ rotation on $C^\dagger Z_2 C = X_1 Z_2$. The two measurements of $Z_1$ and $Z_2$ become measurements of $X_1$ and $X_1 Z_2$, and write to the same bits as before.

With magic states, the rotation becomes an injection on the ancilla qubit 3, whose outcomes $m_1$ and $m_2$ go to the new bits 3 and 4:

julia> c = push!(Circuit(), GateH(), 1);

julia> push!(c, GateCX(), 1, 2);

julia> push!(c, GateT(), 2);

julia> push!(c, Measure(), 1:2, 1:2);

julia> pauli_based_computation(c; magic_states=true)

├── PrepareStateT @ q[3]
├── MP(XZZ) @ q[1:3], c[3]
├── IF(c==0) MP(X) @ q[3], c[4], condition[3]
├── IF(c==1) MP(Y) @ q[3], c[4], condition[3]
├── c[5] ⊻= c[4]
├── c[8] ⊻= c[4]
├── MP(X) @ q[1], c[1]
└── MP(XZ) @ q[1:2], c[2]

The ancilla is measured in X or Y depending on $m_1$ (bit 3). The byproduct $X_1 Z_2$ goes into the frame: bit 5 holds its X part on qubit 1 and bit 8 its Z part on qubit 2. The final measurements commute with it, so their bits are not corrected.

A conditional Pauli and a reset. The Hadamard gate before the conditional $Z_2$ turns it into a conditional $X_2$, and the reset of qubit 1 after its Hadamard gate measures $X_1$ into the new bit 4, then applies $Z_1$ if the outcome is 1:

julia> c = push!(Circuit(), GateH(), 1);

julia> push!(c, Measure(), 1, 1);

julia> push!(c, GateH(), 2);

julia> push!(c, IfStatement(GateZ(), bs"1"), 2, 1);

julia> push!(c, Reset(), 1);

julia> push!(c, Measure(), 1:2, 2:3);

2-qubit, 4-bit circuit with 6 instructions:
├── MP(X) @ q[1], c[1]
├── IF(c==1) X @ q[2], condition[1]
├── MP(X) @ q[1], c[4]
├── IF(c==1) Z @ q[1], condition[4]

MimiqCircuitsBase.cancel_inverses — Method
cancel_inverses(c::Circuit) -> Circuit

Delete pairs of gates that multiply to the identity, such as CX CX, H H or S SDG, also when other gates sit between them as long as the second gate commutes with all of them.

Two gates cancel when one is the inverse of the other on the same qubits, or when the product of their matrices is the identity, which also catches SWAP(1,2) SWAP(2,1). Commutation is checked on the gates' matrices, so for example Z passes a CX control and X passes a CX target; gates with symbolic parameters only pass through each other when both are diagonal.

Multi-controlled X gates (GateCX, GateCCX, GateC3X, Control(n, GateX())) follow structural rules at any width: two of them commute unless the target of one is a control of the other, they commute with diagonal gates that avoid their target and with X rotations that avoid their controls, and two on the same qubits with the same target cancel, whatever the order of the controls. Other gates wider than six qubits are never moved or cancelled.

Non-unitary operations, barriers and classically controlled gates are never moved across, and the search looks back a bounded number of instructions.

Examples

julia> c = push!(Circuit(), GateCX(), 1, 2);

julia> push!(c, GateZ(), 1);            # Z commutes with the CX control...

julia> push!(c, GateCX(), 1, 2);        # ... so the two CX gates cancel

julia> cancel_inverses(c)
1-qubit circuit with 1 instruction:
└── Z @ q[1]

MimiqCircuitsBase.merge_rotations — Method
merge_rotations(c::Circuit) -> Circuit

Merge pairs of rotations of the same kind on the same qubits into one, adding their angles: RZ(a) RZ(b) becomes RZ(a + b), and a pair whose sum is the identity is removed. The two rotations may be separated by gates that commute with the second one, as in cancel_inverses.

Merged gates are GateRX, GateRY, GateRZ, GateP, GateU1, GateR, GateRXX, GateRYY, GateRZZ, GateRZX, GateXXplusYY, GateXXminusYY and RPauli, any of them under the same Control (GateCRZ, GateCP, …). Gates with more than one parameter merge only when the others are equal. Symbolic angles are added symbolically.

Single-qubit gates with numeric parameters also merge across kinds, within families of rotations about the same axis that compose without a global phase:

  • GateZ, GateS, GateSDG, GateT, GateTDG, GateP, GateU1
  • GateX, GateSX, GateSXDG
  • GateY, GateSY, GateSYDG

so T T becomes S and S Z becomes SDG. The result is the named gate when there is one and GateP or GateU otherwise. GateRZ, GateRX and GateRY merge only with themselves, since they differ from the other members of their family by a global phase. Any single-qubit gate with the matrix of one of these, such as a GateU, is treated as that gate.

Examples

julia> @variables θ;

julia> c = push!(Circuit(), GateRZ(θ), 1);

julia> push!(c, GateCZ(), 1, 2);        # diagonal gates commute

julia> push!(c, GateRZ(0.5), 1);

julia> merge_rotations(c)
2-qubit circuit with 2 instructions:
├── RZ(0.5 + θ) @ q[1]
└── CZ @ q[1], q[2]

julia> d = push!(Circuit(), GateT(), 1);

julia> push!(d, GateCX(), 1, 2);        # T on the control commutes with CX

julia> push!(d, GateT(), 1);

julia> merge_rotations(d)               # T T = S
2-qubit circuit with 2 instructions:
├── S @ q[1]
└── CX @ q[1], q[2]

MimiqCircuitsBase.resynthesize_2q — Method
resynthesize_2q(c::Circuit) -> Circuit

Regroup the gates of c into blocks acting on at most two qubits, as fuse does, and rewrite each two-qubit block with the fewest GateCX it needs, between zero and three, found from its KAK decomposition [1] and the circuits of [2].

A block is rewritten only when that lowers its number of two-qubit gates: a SWAP written as three CX gates stays as it is, since it needs all three, while any longer sequence on the same pair of qubits comes down to three or fewer. The rewritten block uses GateCX, GateU and GateRX, GateRY, GateRZ, GateH; follow with resynthesize_1q to merge the single-qubit gates it leaves behind.

Gates with symbolic parameters and non-unitary operations are left alone and end the blocks around them.

Examples

julia> c = Circuit();

julia> for _ in 1:2                     # three CX with rotations in between...
           push!(c, GateCX(), 1, 2)
           push!(c, GateRX(0.3), 1)
       end

julia> push!(c, GateCX(), 1, 2);

julia> count(inst -> numqubits(inst) == 2, resynthesize_2q(c))  # ...need only one
1

MimiqCircuitsBase.resynthesize_linear — Method
resynthesize_linear(c::Circuit) -> Circuit

Rewrite every block made only of GateX, GateCX and GateSWAP gates, of any width, by resynthesizing the map it computes.

Such a block sends the basis state $x$ to $A x \oplus b$ for an invertible Boolean matrix $A$, so it is a classical linear (affine) function of the bits. The block is rebuilt from $A$ with Patel-Markov-Hayes elimination [3], which needs $O(n^2/\log n)$ CX gates for $n$ qubits, followed by one GateX for each set bit of $b$. The rewrite is kept only when it has fewer two-qubit gates than the block, or as many and fewer gates in total. A block that computes the identity is removed.

This finds savings that local passes miss, such as CX ladders that partly undo each other over many qubits. Blocks are collected like fuse does, and end at any other instruction on their qubits.

It is not one of the DEFAULT_SIMPLIFY_PASSES: circuits where CX networks are a small part gain little from it. Pass it to simplify explicitly when they are not.

Examples

julia> c = Circuit();

julia> for _ in 1:2, q in 1:3               # a CX ladder, applied twice...
           push!(c, GateCX(), q, q + 1)
       end

julia> count(inst -> numqubits(inst) == 2, resynthesize_linear(c))  # ...needs 2 CX
2

SymbolicUtils.simplify — Method
simplify(c::Circuit; passes=DEFAULT_SIMPLIFY_PASSES, maxiter=10) -> Circuit

Simplify a circuit by running passes in order, repeatedly, until a round no longer lowers the number of two-qubit gates or, failing that, the total number of instructions. The result has the same unitary as c, global phase included, and the same measurements, resets and other non-unitary operations in the same order.

passes is any collection of functions from Circuit to Circuit. The default, DEFAULT_SIMPLIFY_PASSES, is

  1. remove_identities
  2. cancel_inverses
  3. merge_rotations
  4. resynthesize_2q
  5. resynthesize_1q

resynthesize_linear is not among them: it pays off on circuits with large CX networks, such as arithmetic or error-correction encoders, and costs extra rounds for little on others. Add it where it fits, for example passes=(remove_identities, cancel_inverses, merge_rotations, resynthesize_linear, resynthesize_2q, resynthesize_1q).

Gates are rewritten numerically, so single-qubit runs come out as GateU and named gates such as GateH or GateS may be replaced by it. Pass a subset to keep them, for example passes=(remove_identities, cancel_inverses, merge_rotations). Gates with symbolic parameters are only touched by the first three passes.

Examples

julia> c = push!(Circuit(), GateCX(), 1, 2);

julia> push!(c, GateRZ(0.2), 1);        # RZ commutes with the CX control...

julia> push!(c, GateCX(), 1, 2);        # ...so the two CX gates cancel

julia> push!(c, GateRZ(0.3), 1);        # and the rotations merge

julia> simplify(c)
1-qubit circuit with 1 instruction:
└── RZ(0.5) @ q[1]

MimiqCircuitsBase.CliffordTBasis — Type
CliffordTBasis(; rotations=GridSynthRewrite())
CliffordTBasis(; sk_depth)

Decomposition basis targeting the Clifford+T gate set.

Clifford+T is the standard universal gate set of error-corrected quantum computing. The terminal operations of this basis are those of StimBasis plus GateT and GateTDG, so the two bases always keep the same Clifford and stabilizer operations:

  • single-qubit Cliffords: GateID, GateX, GateY, GateZ, GateH, GateHXY, GateHYZ, GateS, GateSDG, GateSX, GateSXDG, GateSY, GateSYDG;
  • two-qubit Cliffords: GateCX, GateCY, GateCZ, GateSWAP, GateISWAP, GateISWAPDG, GateDCX, GateECR;
  • Pauli rotations by ±π/2: GateRXX, GateRYY, GateRZZ, and RPauli with a non-identity Pauli string;
  • the non-Clifford GateT and GateTDG;
  • measurements, resets and measure-and-resets in the X, Y and Z bases, MeasureXX, MeasureYY, MeasureZZ and MeasurePauli;
  • Pauli noise: PauliX, PauliY, PauliZ, Depolarizing1, Depolarizing2 and PauliNoise;
  • barriers and annotations;
  • classical operations, which StimBasis does not keep;
  • an IfStatement whose body is terminal in this basis, with any condition. StimBasis only keeps a conditional GateX, GateY or GateZ on a single bit.

Decomposition Pipeline

Non-terminal operations are rewritten by the first rule that matches, in this order:

  1. SpecialAngleRewrite: rotations by multiples of π/4 to exact Clifford+T.
  2. ToffoliToCliffordTRewrite: GateCCX to Clifford+T with 7 T gates.
  3. A GateU whose angles are all zero (a pure global phase) is dropped.
  4. ZYZRewrite: GateU to RZ·RY·RZ.
  5. ToZRotationRewrite: GateRX, GateRY to GateRZ and Cliffords.
  6. The rotations rule (default GridSynthRewrite): remaining GateRZ to an approximate Clifford+T sequence.
  7. CanonicalRewrite: any other operation, toward GateU and GateCX.

The rotations rule only sees angles that step 1 could not decompose exactly. The body of an IfStatement goes through the same pipeline and stays conditional. No T-count optimization is performed on the result.

Keyword Arguments

  • rotations::RewriteRule: rule that synthesizes the remaining Z-rotations. The default GridSynthRewrite() approximates each rotation to operator-norm error 1e-10. The rule must match GateRZ with a numeric angle and emit only gates of this basis.
  • sk_depth::Int: use SolovayKitaevRewrite with this recursion depth as the rotations rule.

Throws an ArgumentError if both keywords are given, or if rotations does not match GateRZ. Decomposing an operation that no rule handles, such as a noise channel other than the Pauli ones above, throws a DecompositionError.

Examples

# Decompose to Clifford+T; each arbitrary rotation is approximated to 1e-10
decompose(circuit; basis=CliffordTBasis())

# A looser error bound per rotation gives fewer T gates
decompose(circuit; basis=CliffordTBasis(rotations=GridSynthRewrite(epsilon=1e-6)))

# Solovay-Kitaev at depth 3 instead of gridsynth
decompose(circuit; basis=CliffordTBasis(sk_depth=3))

# Count the T gates of the result
decomposed = decompose(circuit; basis=CliffordTBasis())
t_count = count(inst -> getoperation(inst) isa Union{GateT, GateTDG}, decomposed)

See also DecompositionBasis, StimBasis, CanonicalBasis.

MimiqCircuitsBase.QASMBasis — Type
QASMBasis <: DecompositionBasis

Decomposition basis targeting the OpenQASM 2.0 gate library.

This basis includes all gates defined in qelib1.inc (the standard QASM 2.0 library) plus common extensions, making it suitable for exporting circuits to QASM format or running on QASM-compatible backends.

Terminal Operations

The following gate categories are terminal (not decomposed further):

Fundamental gates (OpenQASM 2.0 built-in):

  • GateU, GateCX — the universal basis for QASM 2.0

Single-qubit gates from qelib1.inc:

  • Legacy U gates: GateU3, GateU2, GateU1
  • Pauli: GateID, GateX, GateY, GateZ
  • Hadamard: GateH
  • Phase: GateS, GateSDG, GateT, GateTDG
  • Rotations: GateRX, GateRY, GateRZ

Two-qubit gates from qelib1.inc:

  • Controlled Paulis: GateCY, GateCZ
  • Controlled Hadamard: GateCH
  • Swap family: GateSWAP
  • Controlled rotations: GateCRX, GateCRY, GateCRZ
  • Ising coupling: GateRXX, GateRZZ

Three-qubit gates from qelib1.inc:

  • GateCCX (Toffoli), GateCSWAP (Fredkin)

Four-qubit gates from qelib1.inc:

  • GateC3X

Non-unitary operations:

  • Measure, Reset, Barrier
  • IfStatement (if inner operation is terminal)

Other operations:

  • GateCall (custom gate invocations)

MeasureReset decomposes into Measure followed by Reset. This leaves the same state and bit as its canonical decomposition, a measurement and a GateX conditioned on its outcome, and unlike that conditional it can be written for a circuit of any number of bits. OpenQASM 2.0 has no loops, so WhileStatement throws a DecompositionError.

Examples

# Decompose to QASM-compatible gates
decompose(circuit; basis=QASMBasis())

# Export to OpenQASM 2.0

MimiqCircuitsBase.StimBasis — Type
StimBasis <: DecompositionBasis

Decomposition basis targeting the Stim stabilizer simulator gate set.

Stim is a high-performance stabilizer circuit simulator by Craig Gidney. It supports only Clifford gates, stabilizer operations, noise channels, and quantum error correction annotations.

Decomposition Pipeline

The basis applies rewrite rules to decompose gates into Clifford operations:

  1. A GateU whose angles are all zero (a pure global phase) is dropped.
  2. ZYZRewrite: GateU → RZ·RY·RZ Euler decomposition
  3. SpecialAngleRewrite (Clifford-only): Rotations at k·π/2 → exact Clifford gates
  4. CanonicalRewrite: Fallback for other gates

Non-Clifford rotations (angles not multiples of π/2) are explicitly rejected with a clear error message.

Clifford-only

Non-Clifford operations (T gates, arbitrary rotations) will cause decomposition to fail. Only rotations with angles that are multiples of π/2 can be decomposed. Use CliffordTBasis for circuits with non-Clifford gates.

Terminal Operations

Single-qubit Clifford gates:

  • Pauli: GateID, GateX, GateY, GateZ
  • Hadamard: GateH, GateHXY, GateHYZ
  • Phase: GateS, GateSDG
  • √X: GateSX, GateSXDG
  • √Y: GateSY, GateSYDG

Two-qubit Clifford gates:

  • Controlled Paulis: GateCX, GateCY, GateCZ
  • Swap: GateSWAP, GateISWAP, GateISWAPDG
  • Double CX: GateDCX
  • ECR: GateECR

Pauli rotations by ±π/2:

  • GateRXX, GateRYY, GateRZZ with angle ±π/2
  • RPauli with angle ±π/2 and a non-identity Pauli string

Angles are compared modulo 2π, since a rotation by 3π/2 equals a rotation by -π/2 up to a global phase. Other angles are decomposed.

Feedback:

  • IfStatement of GateX, GateY or GateZ conditioned on a single bit being 1. The same gate conditioned on the bit being 0 is decomposed into the gate followed by the gate conditioned on 1. Any other conditional operation has its body decomposed while staying conditional, and raises a DecompositionError if that does not lead to a conditional Pauli.

Measurements:

  • Z-basis: Measure
  • X-basis: MeasureX
  • Y-basis: MeasureY
  • Two-qubit parities: MeasureXX, MeasureYY, MeasureZZ
  • Pauli products: MeasurePauli

MimiqCircuitsBase.SolovayKitaevRewrite — Type
SolovayKitaevRewrite <: RewriteRule

Rewrite rule that approximates arbitrary single-qubit unitaries using the Solovay-Kitaev algorithm, producing a sequence of Clifford+T gates.

The algorithm recursively refines an initial approximation using group commutators, achieving ε-approximation with O(log^c(1/ε)) gates where c ≈ 3.97.

Parameters

  • depth::Int: Recursion depth (default: 3). Higher depth = better precision but more gates.
  • simplify::Bool: Whether to simplify the resulting gate sequence (default: true).
  • basis_gates::Vector{AbstractGate}: The basis set to use (default: Clifford+T).
  • net_max_depth::Int: Max depth for generating the initial epsilon-net (default: 15).
  • net_max_points::Int: Max points in the epsilon-net (default: 100,000).
  • net_min_dist::Float64: Minimum distance for epsilon-net points (default: 0.01).

Supported Operations

  • GateRZ(λ) — Z-rotation by angle λ
  • GateRY(θ) — Y-rotation by angle θ
  • GateRX(θ) — X-rotation by angle θ
  • GateU(θ, ϕ, λ, γ) — General single-qubit unitary

Symbolic parameters are not supported.

Output Gates

The decomposition produces gates from the provided basis_gates. For the default Clifford+T basis: GateH, GateS, GateSDG, GateT, GateTDG, GateX, GateY, GateZ.

# Higher precision, custom basis

MimiqCircuitsBase.GridSynthRewrite — Type
GridSynthRewrite(; epsilon=1e-10, seed=0)

Rewrite rule that approximates GateRZ with a Clifford+T sequence, using the Ross–Selinger gridsynth algorithm.

For GateRZ(λ) the rule emits a sequence of GateH, GateS, GateSDG, GateZ, GateT and GateX whose unitary V satisfies min_φ ‖RZ(λ) − e^{iφ}V‖ ≤ epsilon in operator norm. The approximation holds up to a global phase, which is dropped. The T-count is about 3·log₂(1/epsilon) and, except for rare failures of the integer factoring step, optimal among ancilla-free Clifford+T circuits with this error. Angles that are multiples of π/4 give their exact short decomposition.

The factoring step is randomized. For a fixed seed, the same angle and tolerance always give the same sequence. Results are cached per angle, since circuits often repeat the same rotation.

Keyword Arguments

  • epsilon::Real: operator-norm tolerance, 1e-100 ≤ epsilon < 1 (default 1e-10). A rotation takes a few milliseconds at 1e-10 and up to about a second at 1e-100.
  • seed::Integer: seed of the randomized factoring step, in [0, 2^64) (default 0).

Throws an ArgumentError if epsilon or seed is out of range. Decomposing a GateRZ whose angle is not finite throws an ArgumentError.

Supported Operations

  • GateRZ(λ) with a numeric angle λ.

Symbolic angles are not matched. GateRX, GateRY and GateU must first be reduced to Z-rotations, for example with ZYZRewrite and ToZRotationRewrite. CliffordTBasis does this and uses this rule by default.

Examples

# Approximate one rotation to the default tolerance 1e-10
decompose_step(GateRZ(0.123); rule=GridSynthRewrite())

# A coarser tolerance gives fewer T gates
decompose_step(GateRZ(0.123); rule=GridSynthRewrite(epsilon=1e-4))

# Choose the tolerance used by the Clifford+T basis
decompose(circuit; basis=CliffordTBasis(rotations=GridSynthRewrite(epsilon=1e-8)))

References

  • N. J. Ross and P. Selinger, "Optimal ancilla-free Clifford+T approximation of z-rotations", Quantum Inf. Comput. 16, 901 (2016), arXiv:1403.2975.

See also RewriteRule, SolovayKitaevRewrite, CliffordTBasis.

MimiqCircuitsBase.MeasureYY — Type
MeasureYY()

The MeasureYY operation measures the joint parity of two qubits in the Y-basis, that is the two-qubit Pauli operator $Y \otimes Y$. Its decomposition applies an S gate to both qubits, a controlled-X (CX) gate from the first qubit to the second and a Hadamard (H) gate on the first qubit. Together they map $Y \otimes Y$ to $Z$ on the first qubit, which is then measured. The H and CX gates and an S† gate on both qubits are applied afterwards to undo the basis change, so the qubits are left in the post-measurement state of the $Y \otimes Y$ measurement.

A result of 0 indicates that the qubits are in the same state, while a result of 1 indicates that they are in different states.

See Also MeasureXX, MeasureZZ

Examples

julia> c = Circuit()
empty circuit

julia> push!(c, MeasureYY(), 1, 2, 1)
2-qubit, 1-bit circuit with 1 instruction:
└── MYY @ q[1:2], c[1]

MimiqCircuitsBase.MeasurePauli — Type
MeasurePauli(pauli)

Pauli product measurement: projective measurement of the $N$-qubit observable $P = P_1 \otimes P_2 \otimes \dots \otimes P_N$, with each $P_i \in \{I, X, Y, Z\}$.

The instruction targets $N$ qubits and one classical bit. The state is projected onto the $+1$ or $-1$ eigenspace of $P$ and the bit records the outcome: 0 for $+1$, 1 for $-1$. Qubits marked I are targets of the instruction but are not measured.

To measure $-P$, measure $P$ and flip the bit with Not.

Arguments

  • pauli: a PauliString, or a string of I, X, Y, Z.

Throws an ArgumentError if pauli is the identity, since there is nothing to measure.

See also PauliString, RPauli, MeasureZZ, MeasureXX, MeasureYY, pauli_based_computation.

Examples

Measure $X_1 Z_3$ on qubits 1 to 3 and store the outcome in bit 1. Qubit 2 is a target, but is left untouched:

julia> c = push!(Circuit(), MeasurePauli("XIZ"), 1, 2, 3, 1)
3-qubit, 1-bit circuit with 1 instruction:
└── MP(XIZ) @ q[1:3], c[1]

Decomposition

Each measured qubit is rotated to the Z basis (H for X, SDG then H for Y), CX gates collect the parity of the measured qubits on the last one, that qubit is measured, and the CX gates and rotations are undone:

julia> decompose_step(MeasurePauli("XZ"))
2-qubit, 1-bit circuit with 5 instructions:
├── H @ q[1]
├── CX @ q[1], q[2]
├── M @ q[2], c[1]
├── CX @ q[1], q[2]
└── H @ q[1]

Only H, S, SDG, CX and Measure appear, so QASMBasis decomposes it. StimBasis keeps it, as Stim measures Pauli products natively (MPP), and so does CliffordTBasis.

MimiqCircuitsBase.PrepareStateT — Type
PrepareStateT()

Prepare one qubit in the magic state $T\ket{+} = (\ket{0} + e^{i\pi/4}\ket{1})/\sqrt{2}$, whatever its previous state.

A magic state is the resource consumed by a $\pi/8$ Pauli rotation when the rotation is carried out with Pauli product measurements (see pauli_based_computation). Fault-tolerant architectures produce these states separately, by distillation, so a dedicated operation lets them be counted and scheduled.

The operation is a Kraus channel with operators $T\ket{+}\bra{0}$ and $T\ket{+}\bra{1}$, and is equivalent to Reset, GateH, GateT. It cannot be inverted.

See also Reset, ResetX, MeasurePauli.

Examples

└── PrepareStateT @ q[1]

The canonical decomposition resets the qubit to $\ket{0}$, then applies H and T:

├── Reset @ q[1]
├── H @ q[1]

MimiqCircuitsBase.Barrier — Type
Barrier(numqubits)

No-op operation that does not affect the quantum state or the execution of a circuit, but prevents compression or optimization across it.

On some backends (e.g. MPSSim.MPSSimulator), a full-width Barrier — one whose targets cover every qubit in the circuit — additionally acts as a compile-time segment seam: the compiler may pre-compress everything before such a barrier (or after it) into a reusable MPO that is shared across trajectories. Adding such a barrier can therefore materially change memory use in noisy circuits; remove it if you do not want this effect. See is_full_width_barrier.

MimiqCircuitsBase.is_full_width_barrier — Method
is_full_width_barrier(inst, nq::Integer) -> Bool

True iff inst is a single Barrier instruction whose targets cover every qubit index in 1:nq. Conservative reading — a consecutive run of single-qubit Barrier{1}s that together span 1:nq is not recognised here; insert a Barrier(nq) over q[1:nq] if you want a full-width barrier.

Used by backends to identify "safe cut points" where a deterministic prefix can be pre-compressed (or a deterministic suffix can begin) without risk of qubit-shape drift across the seam.

MimiqCircuitsBase.issymbolic — Function
issymbolic(obj)

Checks whether the circuit contains any symbolic (unevaluated) parameters.

This method examines each instruction in the circuit to determine if any parameter remains symbolic (i.e., unevaluated). MimiqCircuitsBase.listvars — Function
listvars(obj)

List the symbolic variables that appear in obj.

obj can be an operation, an Instruction, a Circuit, a ParameterTable or a SweepExperiment:

  • for an operation, the variables in its parameters. Wrappers such as Control, Inverse, Power, Parallel, Repeat, IfStatement and WhileStatement give the variables of the operation they wrap, and a Block those of all its instructions;
  • for an instruction, the variables of its operation;
  • for a circuit, the variables of all its instructions;
  • for a parameter table, the symbols it gives values to, in column order;
  • for a sweep experiment, the symbols of its table, which are those of its circuit.

Returns a Vector{Num} with each variable once, in the order they are first found. It is empty when obj has no symbolic parameters. Variables already substituted by evaluate are not listed.

Examples

 θ
 φ

julia> push!(c, GateRX(2θ), 2);

2-element Vector{Symbolics.Num}:
 θ
 φ

julia> listvars(evaluate(c, Dict(θ => 0.1)))
